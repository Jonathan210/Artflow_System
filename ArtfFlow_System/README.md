# 🎨 ArtFlow System

ArtFlow is a premium, community-driven platform designed for artists to share their creative journey, learn from peers, and manage their artistic projects. Built with a modern **dark glassmorphic** aesthetic, ArtFlow provides a professional yet inspiring environment for digital and traditional artists alike.

## 🚀 Key Features

- **Dynamic Feed**: Explore artworks, lessons, and projects from the community.
- **Role-Based Access**: Specialized views and capabilities for both **Artists** and **Administrators**.
- **Interactive Social Features**:
  - Like, comment, and favorite posts.
  - Follow other artists to stay updated on their progress.
  - Real-time notifications for social interactions.
- **Educational Modules**: Share and discover structured lessons and tutorials.
- **Project Tracking**: Showcase full-scale creative projects from conception to completion.
- **Premium UI/UX**: A state-of-the-art interface featuring:
  - Glassmorphic components.
  - Natural, harmonious color palettes.
  - Smooth transitions and responsive layout.

## 🛠️ Technology Stack

- **Backend**: PHP (MVC Architecture)
- **Database**: MySQL
- **Frontend**: Vanilla JavaScript & CSS (Custom Design System)
- **Environment**: Optimized for XAMPP / Apache

## 📦 Installation & Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/ArtFlow_System.git
   ```

2. **Database Setup**:
   - Start MySQL in your XAMPP Control Panel.
   - Import the `database.sql` file into your local phpMyAdmin or MySQL client.
   - (Optional) Run `seed_db.php` to populate the system with sample data.

3. **Configuration**:
   - Update `config/database.php` with your local database credentials if different from default.

4. **Launch**:
   - Move the project folder to your `htdocs` directory.
   - Navigate to `http://localhost/ArtFlow_System` in your browser.

## 🛡️ Administrative Control

The ArtFlow Admin Dashboard allows for comprehensive management of:
- **User Moderation**: View and manage community members.
- **Content Curation**: Oversight of posts, lessons, and shared projects.
- **System Metrics**: Track community growth and engagement.

## 🎨 Design Philosophy

ArtFlow prioritizes a "Content-First" approach. The interface uses subtle gradients and blur effects to ensure that the artwork remains the focal point while providing a sophisticated user experience.
